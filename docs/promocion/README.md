# Material promocional — EXERSUITE3D

Set de capturas oficiales (1440×810, 16:9) generadas sobre el build real
de la **v0.2.13**, pensadas para la página web y redes sociales. Cada
imagen demuestra un aspecto del flujo de trabajo, las propiedades y los
atributos de la plataforma de diseño y simulación de máquinas de gimnasio.

| # | Imagen | Qué demuestra |
|---|--------|---------------|

| 2 | [`promo-02-asistente.png`](promo-02-asistente.png) | Asistente de nuevo proyecto: modo **Sencillo** (plantear la sala) o **Profesional** (prototipar máquinas al detalle). |
| 3 | [`promo-03-builder-ttp.png`](promo-03-builder-ttp.png) | El Builder con el **rack con torre TTP real** (despiece pieza a pieza), la ventana de comandos izquierda y el Toolbox de herramientas. |
| 4 | [`promo-04-sala.png`](promo-04-sala.png) | Planeamiento de una **sala completa** con las máquinas estándar: jaula, racks, banco plano clásico y árbol de discos, en medidas comerciales (1 celda = 10 cm). |
