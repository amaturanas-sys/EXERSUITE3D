# Extras del kit

- `proyecto-ejemplo.json` — proyecto de prueba (pilar + brazo con bisagra +
  bloque + cadena + maniquí): ábrelo con **Abrir** en el kit de Godot o con
  **Cargar** en la app web (mismo formato).
- `logo-mark.png` / `logo-full.png` / `favicon-32.png` — arte de marca para
  los iconos de exportación (Windows: conviértelo a .ico; Android: úsalo como
  icono adaptativo en el preset de exportación).
